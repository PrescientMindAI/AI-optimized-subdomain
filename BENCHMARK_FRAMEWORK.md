### **2. Quality Metrics**

#### **Query Understanding Score**
- **AI-Optimized**: RefKG query decomposition with priority ranking
- **Standard Website**: Basic keyword matching from HTML scraping
- **Measurement**: Concept extraction accuracy and query decomposition depth

#### **Structured Data Score**
- **AI-Optimized**: Clean, semantic data with relationships
- **Standard Website**: Messy HTML with marketing noise
- **Measurement**: Data structure quality and semantic richness

#### **Trust Indicators Score**
- **AI-Optimized**: Quality certifications, authenticity verification
- **Standard Website**: Limited or no trust indicators
- **Measurement**: Availability and quality of trust signals

#### **Standards Compliance Score**
- **AI-Optimized**: RefKG, I40KG, DPP standards integration
- **Standard Website**: No built-in standards compliance
- **Measurement**: Regulatory and quality standards adherence

### **3. LLM Consumption Metrics**

#### **Token Efficiency**
- **AI-Optimized**: Structured, clean data (150-180 tokens)
- **Standard Website**: Verbose HTML with noise (450-520 tokens)
- **Measurement**: Token count and cost reduction

#### **Processing Speed**
- **AI-Optimized**: Pre-processed, semantic data
- **Standard Website**: Raw HTML requiring parsing
- **Measurement**: Processing time and computational cost
